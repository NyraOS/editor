# nymo

A nano-compatible terminal editor written from scratch in Rust, for [Nyra OS](https://nyraos.com).

## Status

Early development: nothing is usable yet. `nymo --version` is the only thing that works.

## Build and test

Rust 1.85 or newer:

```sh
cargo build
cargo test
```
